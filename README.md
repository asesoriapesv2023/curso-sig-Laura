# curso-sig-laura

Trabajos del curso Servicios SIG y Sitios Web (Maestría SIG, UJdeC).

## Cómo se ejecuta

Los scripts se ejecutan con Python desde PowerShell. Por ejemplo, python scripts\descargar_boyaca.py --out datos descarga las capas de Boyacá en la carpeta datos.

## De dónde salen los datos

Paquete de Boyacá descargado con `scripts/descargar_boyaca.py` (IDE Boyacá y DANE).
Este repositorio es mi práctica de Git y GitHub para la nivelación.
