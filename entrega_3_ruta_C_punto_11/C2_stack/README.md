# C2 — Stack PostGIS, GeoServer y pg_tileserv

El informe documenta Docker Compose, PostGIS, GeoServer, pg_tileserv e importación de municipios de Boyacá.

Verificación a conservar: docker compose ps; GeoServer en localhost:8080; pg_tileserv en localhost:7800/index.json; consulta postgis_version(); nombre de base y contenedores reales.

Nota: el compose consultado usa geodatos, mientras el informe anterior menciona taller_gis. Verificar la ejecución real antes de unificar esa información.
